Core Concepts

Introduction to Dynamic Programming

Dynamic Programming (DP) is an algorithmic optimization technique developed by Richard Bellman in the 1950s. It solves complex problems by breaking them into smaller subproblems, solving each subproblem once, and remembering the results.

1. Overlapping Subproblems

Avoiding repeated work

A problem has overlapping subproblems when a recursive approach computes the exact same subproblem repeatedly. Instead of re-evaluating identical branches millions of times, DP stores calculated answers in a table for instant $O(1)$ lookups.

Example: In Fibonacci recursion, Fib(5) calculates Fib(3) twice and Fib(2) three times. DP reduces operations from $O(2^N)$ to $O(N)$.

2. Optimal Substructure

Composing solutions

A problem has optimal substructure if an optimal solution to the overall problem can be constructed from optimal solutions to its subproblems. If the best package under weight $W$ includes item $i$, then the remaining weight $W - w_i$ must also be packed optimally.

Principle: Optimal choice at step $i$ = $\max(\text{Exclude item}, \; \text{Include item} + \text{Optimal remainder})$.

Comparison of Algorithmic Approaches

Paradigm Approach Data Structure Time Complexity Space Overhead Key Feature
Naive Recursion Top-Down Call Stack only $O(2^N)$ Exponential $O(N)$ Recursion Stack Recomputes identical subtrees repeatedly; slow for large $N$.
Top-Down Memoization Top-Down Lookup Cache Table $O(N \cdot W)$ Polynomial $O(N \cdot W) + O(N)$ Stack Computes subproblems on demand and caches results.
Bottom-Up Tabulation Bottom-Up 2D Matrix $(N+1) \times (W+1)$ $O(N \cdot W)$ Polynomial $O(N \cdot W)$ Matrix Iterative loop; avoids stack overhead; orderly state filling.
Space-Optimized DP Bottom-Up 1D Array of size $(W+1)$ $O(N \cdot W)$ Polynomial $O(W)$ Linear Space Traverses capacity backwards to eliminate redundant table rows.

Real-World Applications of Dynamic Programming

Resource & Budget Allocation

Cloud server VM packing, investment portfolio budgeting, and cargo loading use knapsack DP to maximize profit under fixed capacity.

Bioinformatics & DNA Analysis

Needleman-Wunsch and Smith-Waterman algorithms align DNA and protein sequences to detect genetic mutations using 2D DP matrices.

Text Processing & Version Control

Levenshtein Edit Distance powers spell-checkers, auto-correct, and git diff by finding minimal insertions, deletions, and edits.

Navigation & Shortest Routes

Bellman-Ford and DAG shortest path algorithms dynamically calculate optimal travel routes across network routers and road networks.

Student 1 & 2: Formulation & Table Construction

0/1 Knapsack Problem Demonstration

Given $N$ items, each with a specific weight $w_i$ and value $v_i$, and a knapsack with maximum weight capacity $W$. Find the subset of items that maximizes total value without exceeding capacity $W$.

Why is it Called "0/1"?

Each item can either be taken completely once ($x_i = 1$) or not taken ($x_i = 0$). Fractional selection is not allowed.

Why Greedy Fails: Sorting items by value/weight ratio works for fractional knapsack, but fails in 0/1 knapsack because high-ratio items can leave unused capacity that prevents fitting a better combination of items.

Complexity Analysis & Benchmarks

Rigorous comparison between Brute Force Recursion, Top-Down Memoization, Bottom-Up Tabulation, and 1D Space-Optimized DP.

Brute Force Recursion

Explores all $2^N$ subsets; exponential overhead

Time: O(2N) • Space: O(N)

Top-Down Memoization

Evaluates subproblems on demand with table cache

Time: O(N × W) • Space: O(N × W) + O(N)

Bottom-Up Tabulation

Iterative matrix filling; no stack recursion

Time: O(N × W) • Space: O(N × W)

Space-Optimized DP (1D Array)

Traverses backwards; compresses 2D matrix to 1 row

Time: O(N × W) • Space: O(W)

C Source Code Implementations

Clean, well-commented ANSI C code demonstrating all 4 paradigms of the 0/1 Knapsack Problem with sample test drivers. 

/* ============================================================================
 * Dynamic Programming Optimization Toolkit - 0/1 Knapsack in Pure C
 * Compiles cleanly with: gcc -O2 knapsack.c -o knapsack
 * ============================================================================ */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    int id, weight, value;
} Item;

static inline int max(int a, int b) { return (a > b) ? a : b; }

/* 1. Naive Recursion: O(2^N) Time, O(N) Space */
int knapsackRecursive(int i, int w, const Item items[]) {
    if (i < 0 || w <= 0) return 0;
    if (items[i].weight > w)
        return knapsackRecursive(i - 1, w, items);
    
    int exclude = knapsackRecursive(i - 1, w, items);
    int include = items[i].value + knapsackRecursive(i - 1, w - items[i].weight, items);
    return max(exclude, include);
}

/* 2. Top-Down Memoization: O(N * W) Time & Space */
int knapsackMemoized(int i, int w, const Item items[], int memo[][101]) {
    if (i < 0 || w <= 0) return 0;
    if (memo[i][w] != -1) return memo[i][w];
    if (items[i].weight > w)
        return memo[i][w] = knapsackMemoized(i - 1, w, items, memo);

    int exclude = knapsackMemoized(i - 1, w, items, memo);
    int include = items[i].value + knapsackMemoized(i - 1, w - items[i].weight, items, memo);
    return memo[i][w] = max(exclude, include);
}

/* 3. Bottom-Up Tabulation (2D Table) with Backtracking */
int knapsackTabulation(int n, int W, const Item items[], int chosen[], int *chosenCount) {
    int dp[51][101];
    memset(dp, 0, sizeof(dp));

    for (int i = 1; i <= n; i++) {
        int wt = items[i - 1].weight;
        int val = items[i - 1].value;
        for (int w = 0; w <= W; w++) {
            if (wt > w) dp[i][w] = dp[i - 1][w];
            else dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - wt] + val);
        }
    }

    /* Backtrack selected items */
    *chosenCount = 0;
    int currW = W;
    for (int i = n; i > 0; i--) {
        if (dp[i][currW] != dp[i - 1][currW]) {
            chosen[(*chosenCount)++] = items[i - 1].id;
            currW -= items[i - 1].weight;
        }
    }
    return dp[n][W];
}

/* 4. Space-Optimized Tabulation: O(W) Space */
int knapsackSpaceOptimized(int n, int W, const Item items[]) {
    int dp[101] = {0};
    for (int i = 0; i < n; i++) {
        for (int w = W; w >= items[i].weight; w--) {
            dp[w] = max(dp[w], dp[w - items[i].weight] + items[i].value);
        }
    }
    return dp[W];
}

int main(void) {
    Item items[] = { {1,2,3}, {2,3,4}, {3,4,5}, {4,5,6} };
    int n = 4, W = 5, chosen[10], count = 0;
    int ans = knapsackTabulation(n, W, items, chosen, &count);
    printf("Optimal Max Profit: %d\n", ans);
    return 0;
}
/* 1. Naive Recursion in C: O(2^N) Time, O(N) Space */
int knapsackRecursive(int i, int w, const Item items[]) {
    // Base Case: No items or no capacity left
    if (i < 0 || w <= 0) return 0;

    // If item weight exceeds capacity, it cannot be included
    if (items[i].weight > w)
        return knapsackRecursive(i - 1, w, items);

    // Take maximum of excluding vs including
    int exclude = knapsackRecursive(i - 1, w, items);
    int include = items[i].value + knapsackRecursive(i - 1, w - items[i].weight, items);

    return max(exclude, include);
}
/* 2. Top-Down Memoization in C: O(N * W) Time, O(N * W) Space */
int knapsackMemoized(int i, int w, const Item items[], int memo[][101]) {
    if (i < 0 || w <= 0) return 0;

    // Return cached answer if previously computed
    if (memo[i][w] != -1) return memo[i][w];

    if (items[i].weight > w)
        return memo[i][w] = knapsackMemoized(i - 1, w, items, memo);

    int exclude = knapsackMemoized(i - 1, w, items, memo);
    int include = items[i].value + knapsackMemoized(i - 1, w - items[i].weight, items, memo);

    return memo[i][w] = max(exclude, include);
}
/* 3. Bottom-Up Tabulation in C: O(N * W) Time & Space */
int knapsackTabulation(int n, int W, const Item items[], int chosen[], int *chosenCount) {
    int dp[51][101];
    memset(dp, 0, sizeof(dp));

    for (int i = 1; i <= n; i++) {
        int wt = items[i - 1].weight;
        int val = items[i - 1].value;
        for (int w = 0; w <= W; w++) {
            if (wt > w) {
                dp[i][w] = dp[i - 1][w];
            } else {
                dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - wt] + val);
            }
        }
    }

    /* Backtracking to identify chosen items */
    *chosenCount = 0;
    int currW = W;
    for (int i = n; i > 0; i--) {
        if (dp[i][currW] != dp[i - 1][currW]) {
            chosen[(*chosenCount)++] = items[i - 1].id;
            currW -= items[i - 1].weight;
        }
    }
    return dp[n][W];
}
/* 4. Space-Optimized Tabulation in C: O(N * W) Time, O(W) Space */
int knapsackSpaceOptimized(int n, int W, const Item items[]) {
    int dp[101] = {0};

    for (int i = 0; i < n; i++) {
        // Traverse backwards from W down to item weight
        for (int w = W; w >= items[i].weight; w--) {
            dp[w] = max(dp[w], dp[w - items[i].weight] + items[i].value);
        }
    }

    return dp[W];
}
/* ============================================================================
 * Dynamic Programming Optimization Toolkit - Floyd-Warshall in Pure C
 * All-Pairs Shortest Path: O(V^3) Time, O(V^2) Space
 * Compiles cleanly with: gcc -O2 floyd_warshall.c -o floyd_warshall
 * ============================================================================ */
#include <stdio.h>
#include <stdlib.h>

#define V 4
#define INF 99999

/* Triple nested Dynamic Programming loops */
void floydWarshall(int dist[V][V], int nextNode[V][V]) {
    for (int k = 0; k < V; k++) {
        for (int i = 0; i < V; i++) {
            for (int j = 0; j < V; j++) {
                if (dist[i][k] < INF && dist[k][j] < INF) {
                    if (dist[i][k] + dist[k][j] < dist[i][j]) {
                        dist[i][j] = dist[i][k] + dist[k][j];
                        nextNode[i][j] = nextNode[i][k];
                    }
                }
            }
        }
    }
}

int main(void) {
    int dist[V][V] = {
        {0,   3,   INF, 7  },
        {8,   0,   2,   INF},
        {5,   INF, 0,   1  },
        {2,   INF, INF, 0  }
    };
    int nextNode[V][V];
    for (int i = 0; i < V; i++)
        for (int j = 0; j < V; j++)
            nextNode[i][j] = (i != j && dist[i][j] < INF / 2) ? j : -1;

    floydWarshall(dist, nextNode);
    printf("All-pairs shortest paths computed in O(V^3) time!\n");
    return 0;
}
